# JobChecker-Django

This is a small Django project that I made while learning Django.

The project checks whether a person is eligible for a job based on their age, experience and Python skill.

## What this project does

The user enters:

- Name
- Age
- Experience
- Python Skill (Yes/No)

After submitting the form, the application checks the details and shows whether the person is eligible for the job or not.

## Eligibility

The person is eligible if:

- Age is 18 or above
- Experience is 1 year or more
- Python skill is Yes

Otherwise, it shows "Not Eligible for Job".
